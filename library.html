Rigs

A Rig is one optical configuration. It claims files by camera and focal-length range, and optionally by patterns matched against the Optical Train (ignoring case; * matches anything). A file matching no Rig is unassigned, and one matching several is ambiguous and left unassigned.

Suggested Rigs

Unassigned Optical Trains grouped by camera and by focal lengths within 3% of each other, so the same set-up written several ways appears once. "Use" fills the form below; check the id and name, then save.

Add or edit a Rig

The from and to values are the measured range that decides which files belong to the Rig. The nominal value is only what is shown: set it to the maker's figure.

Content hashes

A sub needs a Content hash before it can go into a Checkout. Hashing runs by itself after every scan and Source pull, in idle time: it pauses while a scan is running or waiting and carries on afterwards. It covers files under the library roots and Source Mirrors.
